# ML from Scratch

Personal learning repo for implementing classic deep learning models from scratch.

## Goal

**Land an AI engineer job at OpenAI-like companies** (frontier AI labs).

Everything here is in service of that: deeply understand how models work by
building them from scratch, the kind of fundamentals these interviews and roles expect.

## Planned implementations

Work through these in order. Everything builds on the MLP. CNN and RNN are two
separate branches (weight sharing across space vs. across time), so you can study
them in either order. From RNN onwards, each module builds directly on the previous one.

- [ ] Multi-Layer Perceptron (MLP): [`mlp/`](mlp/)
- [ ] Convolutional Neural Network (CNN): [`cnn/`](cnn/)
- [ ] Recurrent Neural Network (RNN): [`rnn/`](rnn/)
- [ ] LSTM / GRU: [`lstm/`](lstm/)
- [ ] Seq2seq + Attention: [`attention/`](attention/)
- [ ] Transformer (GPT-style): [`transformer/`](transformer/)

```
MLP ──┬──> CNN
      └──> RNN ──> LSTM / GRU ──> Seq2seq + Attention ──> Transformer
```

## Structure

Each model lives in its own folder (`mlp/`, `cnn/`, `rnn/`, `lstm/`, `attention/`, `transformer/`) with:

- `README.md`: the theory, with **pictures** (in `images/`, generated by `make_figures.py`), interview questions and exercises
- a **step-by-step terminal visual** (`*_visual.py`) that shows the computation as it happens
- a from-scratch **NumPy** implementation with a gradient check
- the same model in **PyTorch**

## Setup

Run these commands from the repository root. Python 3.11 is a tested option.

### Windows (PowerShell)

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Use the environment's Python directly; activation is not required:

```powershell
.\.venv\Scripts\python.exe mlp\gradient_check.py
.\.venv\Scripts\python.exe rnn\gradient_check.py
.\.venv\Scripts\python.exe cnn\gradient_check.py
.\.venv\Scripts\python.exe lstm\gradient_check.py
.\.venv\Scripts\python.exe attention\gradient_check.py
.\.venv\Scripts\python.exe transformer\gradient_check.py
.\.venv\Scripts\python.exe mlp\mlp_numpy.py
```

To open Jupyter:

```powershell
.\.venv\Scripts\python.exe -m jupyter notebook
```

### macOS / Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python mlp/gradient_check.py
python rnn/gradient_check.py
python cnn/gradient_check.py
python lstm/gradient_check.py
python attention/gradient_check.py
python transformer/gradient_check.py
```

Each folder's `README.md` has a "Suggested order" for its scripts.
